Step 3 — Securely store the uploaded file
Now that PHP receives and validates the file, let's actually save it.

1. Create an uploads directory
Your project structure:


text
appmanager/
├── resources/
│   └── php/
│       └── fh7.php
└── uploads/
2. Generate a unique filename
Never trust the original filename.


php
$newName = bin2hex(random_bytes(16)) . "." . $extension;
Example:


text
Original: myphoto.jpg

Generated: 8f3a91b7c2d4e6a1.jpg
random_bytes(16) generates 16 random bytes.

bin2hex() converts them into hexadecimal characters.

$extension preserves the validated extension.

3. Move the uploaded file

php
$uploadDir = __DIR__ . '/../../uploads/';

if (!is_dir($uploadDir)) {
    mkdir($uploadDir, 0755, true);
}

$destination = $uploadDir . $newName;

if (!move_uploaded_file($file['tmp_name'], $destination)) {
    http_response_code(500);

    echo json_encode([
        "status" => false,
        "message" => "Failed to save file"
    ]);

    exit;
}
Understand move_uploaded_file():


php
move_uploaded_file(
    $file['tmp_name'],
    $destination
);
First argument: Temporary file location.

Second argument: Final destination.

It moves the uploaded file from PHP's temporary directory into your uploads directory.

4. Return success to JavaScript
After successfully moving the file:


php
echo json_encode([
    "status" => true,
    "message" => "File uploaded successfully",
    "filename" => $newName
]);

exit;
5. Final JavaScript response handling

javascript
const result = await response.json();

if (!response.ok || !result.status) {
    console.error(result.message);
    return;
}

console.log(result.message);
console.log("Saved filename:", result.filename);
Important security note
For production:

Keep uploads outside the public web root where possible.

Disable script execution in the upload directory.

Validate extension, MIME type and file size before moving.

Restrict access to uploaded files.

Concept covered: move_uploaded_file() transfers a validated PHP upload from temporary storage to permanent storage.
