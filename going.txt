Batch 2: File operations and directory handling
Three concepts. Let's go.

1. unlink() – Delete a file
Deletes a file.


php
$file = "app.txt";

if (file_exists($file)) {
    if (unlink($file)) {
        echo "File deleted";
    }
}
Interview points:

unlink() deletes files, not directories.

Returns true on success and false on failure.

Requires appropriate filesystem permissions.

2. copy() and rename()
copy() – Copy a file
Original file remains untouched.


php
if (copy("app.txt", "backup.txt")) {
    echo "File copied";
}
Result:


text
app.txt       → Original
backup.txt    → Copy
rename() – Rename or move a file

php
rename("app.txt", "new_app.txt");
You can also move a file to another directory:


php
rename("app.txt", "backup/app.txt");
Important interview difference:

Function

Behaviour

copy()

Creates another copy

rename()

Renames or moves the original

unlink()

Deletes the file

3. Directory handling
These are the important Core PHP functions.

mkdir() – Create directory

php
mkdir("uploads");
Create nested directories:


php
mkdir("uploads/images", 0777, true);
The third argument true enables recursive directory creation.

rmdir() – Remove directory

php
rmdir("uploads");
Important: Directory must be empty.

scandir() – List directory contents

php
$files = scandir("uploads");

print_r($files);
Returns an array of directory entries, including . and ...

is_dir() and is_file()

php
$path = "uploads";

if (is_dir($path)) {
    echo "It's a directory";
}

if (is_file("app.txt")) {
    echo "It's a file";
}
Remember:

file_exists() → Checks whether a path exists.

is_file() → Checks whether it's a regular file.

is_dir() → Checks whether it's a directory.
