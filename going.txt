Batch 3: File Uploads and File Security (Core PHP)
Let's cover three concepts.

1. File Upload – $_FILES
PHP uses the $_FILES superglobal to handle uploaded files.

HTML form:

<form method="POST" enctype="multipart/form-data">
    <input type="file" name="myfile">
    <button type="submit">Upload</button>
</form>
PHP code:


php
if (isset($_FILES['myfile'])) {

    $file = $_FILES['myfile'];

    move_uploaded_file(
        $file['tmp_name'],
        "uploads/" . $file['name']
    );

    echo "File uploaded";
}
Understand $_FILES
PHP provides these important properties:

Property

Meaning

name

Original filename

tmp_name

Temporary file location

size

File size in bytes

type

Browser-reported MIME type

error

Upload error code

Important concept:

tmp_name → Where PHP temporarily stores the uploaded file.

name → Original filename.

move_uploaded_file() → Moves the uploaded file to your destination.

2. File Upload Validation
Never trust uploaded files.

Before uploading, validate:

File extension.

File size.

Actual file type.

Upload error.

Example:


php
if (isset($_FILES['myfile'])) {

    $file = $_FILES['myfile'];

    $allowed = ['jpg', 'png', 'pdf'];

    $extension = strtolower(
        pathinfo($file['name'], PATHINFO_EXTENSION)
    );

    if ($file['error'] !== UPLOAD_ERR_OK) {
        die("Upload failed");
    }

    if (!in_array($extension, $allowed)) {
        die("Invalid file extension");
    }

    if ($file['size'] > 2 * 1024 * 1024) {
        die("File too large");
    }

    echo "File validation successful";
}
Remember:

pathinfo() → Extracts file information.

PATHINFO_EXTENSION → Gets file extension.

strtolower() → Converts text to lowercase.

in_array() → Checks whether a value exists in an array.

UPLOAD_ERR_OK → Upload completed successfully.

Note: Extension checking alone is not sufficient. Use server-side MIME validation with finfo_file() as well.

3. File Security
Three important security practices.

A. Never trust original filenames
Bad:


php
move_uploaded_file(
    $file['tmp_name'],
    "uploads/" . $file['name']
);
Better:


php
$newName = bin2hex(random_bytes(16)) . "." . $extension;

move_uploaded_file(
    $file['tmp_name'],
    "uploads/" . $newName
);
Why?

Prevents filename collisions.

Avoids trusting user-provided filenames.

Makes filenames unpredictable.

B. Validate actual file type

php
$finfo = finfo_open(FILEINFO_MIME_TYPE);

$mime = finfo_file($finfo, $file['tmp_name']);

finfo_close($finfo);

echo $mime;
This checks the file's MIME type using its contents rather than trusting the browser.

C. Store uploads safely
Avoid storing uploaded files in publicly executable directories.

Prefer:

Store uploads outside the public web root.

Restrict access to uploaded files.
