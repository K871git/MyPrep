2. Interface — contract
Concept: An interface defines what a class MUST implement.

resources/php/interfaces/TaskInterface.php


php

interface TaskInterface
{
    public function getId(): string;

    public function getTitle(): string;

Interface contains method declarations.

A class uses implements.

Implemented methods must be public.

A class can implement multiple interfaces.

3. Abstract class
Concept: An abstract class provides a common parent with shared functionality.

resources/php/abstract/BaseTask.php


php
<?php

abstract class BaseTask implements TaskInterface
{
    protected string $id;
    protected string $title;

    public function __construct(string $id, string $title)
    {
        $this->id = $id;
        $this->title = $title;
    }

    public function getId(): string
    {
        return $this->id;
    }

    public function getTitle(): string
    {
        return $this->title;
    }

<?php

require_once __DIR__ . '/../interfaces/TaskInterface.php';
require_once __DIR__ . '/../abstract/BaseTask.php';
require_once __DIR__ . '/../traits/TimestampTrait.php';

class Task extends BaseTask
{
    use TimestampTrait;

    private bool $completed;

    public function __construct(
        string $id,
        string $title,
        bool $completed = false
    ) {
        parent::__construct($id, $title);

        $this->completed = $completed;
    }

    public function isCompleted(): bool
    {
        return $this->completed;
    }

    public function toArray(): array
    {
        return [
            "id" => $this->id,
            "title" => $this->title,
            "completed" => $this->completed,
            "created_at" => $this->createdAt()
        ];
    }
}

Example:

Understand

Multiple catch blocks

php

    // risky code

    echo "Validation error";

    echo "Database error";

PART 3 — Business logic and algorithms
7. TaskService
This is where we keep our business logic.

Instead of putting everything inside the API file, we separate responsibilities.

resources/php/services/TaskService.php


php
<?php

require_once __DIR__ . '/../models/Task.php';
require_once __DIR__ . '/../exceptions/ValidationException.php';

class TaskService
{
    private string $file;

    public function __construct()
    {
        $this->file = __DIR__ . '/../tasks.json';

        if (!file_exists($this->file)) {
            file_put_contents($this->file, '[]');
        }
    }

    // READ ALL
    public function getAll(): array
    {
        $data = json_decode(
            file_get_contents($this->file),
            true
        );

        return is_array($data) ? $data : [];
    }

    // CREATE
    public function create(string $title): array
    {
        $title = trim($title);

        if ($title === '') {
            throw new ValidationException("Title is required");
        }

        $tasks = $this->getAll();

        $task = new Task(
            bin2hex(random_bytes(8)),
            $title
        );

        $tasks[] = $task->toArray();

        $this->save($tasks);

        return $task->toArray();
    }

    // SEARCH
    public function search(string $keyword): array
    {
        $tasks = $this->getAll();

        return array_values(array_filter(
            $tasks,
            function ($task) use ($keyword) {

                return stripos(
                    $task['title'],
                    $keyword
                ) !== false;
            }
        ));
    }

    // FILTER COMPLETED
    public function completed(): array
    {
        $tasks = $this->getAll();

        return array_values(array_filter(
            $tasks,
            fn($task) => $task['completed'] === true
        ));
    }

    // SORT ALPHABETICALLY
    public function sortTasks(): array
    {
        $tasks = $this->getAll();

        usort($tasks, function ($a, $b) {
            return strcmp($a['title'], $b['title']);
        });

        return $tasks;
    }

    // SAVE DATA
    private function save(array $tasks): void
    {
        $json = json_encode(
            $tasks,
            JSON_PRETTY_PRINT
        );

        if ($json === false ||
            file_put_contents($this->file, $json, LOCK_EX) === false) {

            throw new RuntimeException("Unable to save tasks");
        }
    }
}

function findTask(array $tasks, string $id): ?array
{
    foreach ($tasks as $task) {

        if ($task['id'] === $id) {
            return $task;
        }
    }

    return null;
}
Algorithm explanation:

Start from the first task.

Compare its ID.

If it matches, return the task.

10. PHP API endpoint
resources/php/api.php


php
<?php

require_once __DIR__ . '/services/TaskService.php';

header("Content-Type: application/json; charset=UTF-8");

function response(
    int $status,
    bool $success,
    string $message,
    mixed $data = null
): void {

    http_response_code($status);

    echo json_encode([
        "success" => $success,
        "message" => $message,
        "data" => $data
    ]);

    exit;
}

try {

    $service = new TaskService();

    $method = $_SERVER['REQUEST_METHOD'];

    switch ($method) {

        // GET
        case 'GET':

            if (isset($_GET['q'])) {

                $tasks = $service->search($_GET['q']);

            } elseif (isset($_GET['completed'])) {

                $tasks = $service->completed();

            } elseif (isset($_GET['sort'])) {

                $tasks = $service->sortTasks();

            } else {

                $tasks = $service->getAll();
            }

            response(200, true, "Tasks fetched", $tasks);

            break;

        // POST
        case 'POST':

            $input = json_decode(
                file_get_contents("php://input"),
                true
            );

            if (!is_array($input)) {
                throw new ValidationException("Invalid JSON body");
            }

            $title = $input['title'] ?? '';

            if (!is_string($title)) {
                throw new ValidationException("Title must be text");
            }

            $task = $service->create($title);

            response(201, true, "Task created", $task);

            break;

        default:

            header("Allow: GET, POST");

            response(405, false, "Method not allowed");
    }

} catch (ValidationException $e) {

    response(422, false, $e->getMessage());

} catch (Throwable $e) {

    error_log($e->getMessage());

    response(500, false, "Internal server error");
}

14. JavaScript fetch API
resources/js/app.js


javascript
const API = "index.php?api=tasks";

const form = document.getElementById("taskForm");
const title = document.getElementById("title");
const taskList = document.getElementById("taskList");
const message = document.getElementById("message");
const search = document.getElementById("search");


// GET TASKS
async function getTasks(keyword = "") {

    try {

        const url = keyword
            ? `${API}&q=${encodeURIComponent(keyword)}`
            : API;

        const res = await fetch(url);

        if (!res.ok) {
            throw new Error("Request failed");
        }

        const result = await res.json();

        if (!result.success) {
            throw new Error(result.message);
        }

        displayTasks(result.data);

    } catch (error) {

        message.textContent = error.message;

    }
}


// DISPLAY TASKS
function displayTasks(tasks) {

    taskList.innerHTML = "";

    tasks.forEach(task => {

        const li = document.createElement("li");

        li.textContent = task.title;

        taskList.appendChild(li);

    });
}


// CREATE TASK
form.addEventListener("submit", async function (e) {

    e.preventDefault();

    try {

        const res = await fetch(API, {

            method: "POST",

            headers: {
                "Content-Type": "application/json"
            },

            body: JSON.stringify({
                title: title.value
            })

        });

        const result = await res.json();

        if (!res.ok || !result.success) {
            throw new Error(result.message);
        }

        message.textContent = "Task created successfully";

        title.value = "";

        getTasks();

    } catch (error) {

        message.textContent = error.message;

    }

});


// SEARCH
search.addEventListener("input", function () {

    getTasks(search.value);

});


// INITIAL LOAD
getTasks();
